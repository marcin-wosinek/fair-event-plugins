The List tab of an event date has a **Print list** button. It opens a print
preview naming the event and its date, with every confirmed ticket of the
List — one row per ticket, in the List's order and numbering, with ticket
type, extras, status, transaction, mailing consent and registration date —
whatever screen filter is on. The preview prints in landscape, repeats the
table header on each page, and splits a table with many extras into parts
that repeat the row number and ticket. Email addresses, amounts and the
List's actions are left out.
