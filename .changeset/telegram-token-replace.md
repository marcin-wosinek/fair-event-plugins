With a Telegram bot token saved, Weekly notifications now shows "A bot token is saved" without a token field. You can change the schedule, chats or other settings and save them without re-entering the token. Browser autofill can no longer replace the token or block the save. To change the token, choose "Replace bot token". "Keep saved token" discards the new value. If the new token is rejected, the saved token and other settings stay unchanged and the new value stays in the field so you can correct it.
