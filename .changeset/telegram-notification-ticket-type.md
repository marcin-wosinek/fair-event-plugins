Payment notifications (Telegram and email) now name the ticket type bought with that payment. Before, when someone who already had a ticket for an event bought another, the notification showed their earlier ticket type. A payment covering several purchases lists each ticket type and shows the event only when they're all for the same one. When the purchase can't be found, the notification leaves out the ticket, event and activities instead of guessing.
