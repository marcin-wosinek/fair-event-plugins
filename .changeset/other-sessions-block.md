Add an Other Sessions block that lists the upcoming sessions of a recurring
event, each linking to its own session page. Place it anywhere on the event's
page, separately from Event Info. On a session page it leaves that session
out. Entries show the full date, only the times that were set (an end time
alone is labelled as the end), the session's own venue, and an "All day" mark
for all-day sessions. Ongoing sessions stay listed until they end. The block
shows 5 sessions by default (1–20 in its settings), says when there is nothing
left to attend, and explains in the editor when the page has no recurring
event.
