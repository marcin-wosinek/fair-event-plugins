The Event notifications list matches the other admin lists. Each row shows Edit on the right, and History, Duplicate and Delete are in the row's "⋮" menu. Unsaved changes and anything keeping a notification from sending are shown under its name. Duplicating shows its progress and any error in the row, with Try again. When the list cannot be refreshed, a message says so with Try again while the shown notifications and unsaved changes stay. A search that matches nothing can be cleared with one click. On tablets and phones each notification is shown as a labeled block.
