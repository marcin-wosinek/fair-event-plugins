Budgets, financial entries, reconciliation and settlements are now fully translated on sites running in German, Spanish, French or Polish. Text that still belonged to Fair Payments Connector's translations — and so stayed in English — now uses Fair Finance's own, with the existing translations carried over. Wording is unchanged.

The admin screens' JavaScript translations are now loaded too, and **Settings → Fair Event Plugins** gains a Fair Finance row to load the translation files shipped with the plugin instead of WordPress.org language packs.
