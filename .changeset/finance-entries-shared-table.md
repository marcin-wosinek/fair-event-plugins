The Finance Entries list is easier to scan. Each entry's description comes first, with its tag, payment source, participant and, for split and transfer entries, a "Show allocations" toggle underneath. Amounts are right-aligned, and the Matched column reads "Yes" or "No" with a marker. Each row now shows one action: Edit, or Edit split for split entries and their allocations. Split, Match or Unmatch, and Delete are in each row's "⋮" menu, and a split entry's Delete explains that it must be unsplit first. Expanded allocations name the entry they belong to. If the list fails to load or refresh, a Try again button reloads it without losing the rows already shown, and filters that match nothing offer Clear filters. On tablets and phones each entry is shown as a labeled block instead of a wide table.
