Remove the old Fair Audience Event Signup block. Pages that still contain it keep working: they now show the Event Signup form, with their button text and custom questions in the same order. A saved form that asks for a file upload shows a notice to contact the organizer instead, because the Event Signup form does not accept uploads. In the editor, old pages show the block as unsupported and it can be replaced with Event Signup.

The Event Signup form now protects existing participants. When a visitor types the email of someone already known to the site, and is not recognised as that person, nothing is saved and a link is sent to that address. Opening the link brings back the ticket choice and answers so the signup can be finished. Signed-in members and visitors arriving from their own link continue as before.
