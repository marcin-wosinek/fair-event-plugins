The Payment Transactions list is easier to scan. Each row starts with the transaction reference and its description, followed by the person, date, amount, status and matched entry. Both fees appear under the amount with their currency, the status is labeled text such as "Paid" or "Pending payment" with Test mode or Live mode underneath, and each row has a View details link. Column headers sort from the keyboard. On tablets and phones each transaction is shown as a labeled block, with Sort by and Select all controls above the list. If a refresh fails, the rows already shown and your selection stay in place with a Try again button. Changing filters, sorting or the page no longer shows the previous results while the new ones load.
