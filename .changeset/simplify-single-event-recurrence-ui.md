Simplify the Manage Event page's recurrence section for single (non-series) events. Instead of a "Recurrence" card with a heading and "This event happens once." text, a single event now shows just the "Turn into a series" button directly below the date/time fields, with no card wrapper. Events already part of a series are unchanged — they keep the recurrence summary, "Edit series"/"End series" controls, and occurrence calendar.
