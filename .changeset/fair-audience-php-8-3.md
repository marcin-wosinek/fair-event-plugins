Fair Audience now requires PHP 8.3. Upgrade your site to PHP 8.3 or newer before updating the plugin. Sites still on PHP 8.2 keep working on the release they already have, but WordPress won't install this or any later Fair Audience release there, so they also stop receiving fixes, including security fixes. The library that builds ZIP files for spreadsheet exports moves to its current 3.2 line, which needs PHP 8.3.
