The Event Feeds list is more compact. Each feed's name and slug now share one column, the status reads "Enabled" or "Disabled" with a marker instead of a colored badge, and Edit is the only button shown on each row. Copy iCal feed URL, Copy JSON API URL and Delete are in each row's "⋮" menu. Copying confirms which feed's URL was copied, and if the browser blocks the clipboard the message shows the URL to copy by hand. On tablets and phones each feed is shown as a labeled block instead of a wide table.
