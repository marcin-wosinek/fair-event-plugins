Make the Meta tests in the Experimental settings easier to use. The calendar click test now picks its event from a searchable list that shows the latest events with an event page straight away and keeps the choice through later searches. Every disabled test button says why, consent can be checked again without losing the chosen event, and a password manager no longer fills the access token field and silently disables the tests. "Discard changes" restores the saved settings.
