Add an experimental team member directory (Fair Events → Team members, off by default in Settings → Experimental). Administrators keep sitewide profiles with name, surname, contact details and grammatical gender, and add people to an event's team in Manage Event → Event Details; a series shares one team across all its dates, and event copies start with their source's team. Contact details stay private to administrators. Fair Events gains a `fair_events_event_copy_extensions` filter so companion plugins can copy their own data with an event.
