The **Entries** page now shows how many financial entries are still waiting for a budget, above the entries table. The number covers the whole ledger, whatever filters, page or sorting the table shows. It counts each split allocation without a budget, not the split entry itself. It updates after you save, delete, import, split, unsplit, match or unmatch an entry, or save a transfer. While the number is loading the page says so, and if it can't be loaded you can retry, so neither is shown as zero.
