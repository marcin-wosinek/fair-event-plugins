The Organizer settings tab now shows the site's actual name, logo, and website as live placeholders, with a clear way to override each per-field. Added an optional contact point (email/phone), emitted as a Schema.org `ContactPoint` on the sitewide Organization block. Blank fields keep today's behaviour (site name + home URL, theme logo), so existing sites see no change until an admin opts in.
