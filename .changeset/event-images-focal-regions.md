Add event images: with the new opt-in Event images feature, the Manage Event Images tab links ordered Media Library images to an event and to each of its saved programme items, each with an optional circle marking what must stay visible when the image is cropped. A series keeps its images on the series. An authenticated API returns the images, their oriented sizes and circles for tools such as Event Content Studio (see docs/event-images.md).
