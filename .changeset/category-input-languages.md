Show category languages in the calendar's Quick Add Event popup. Quick Add and Manage Event now share one category input that lists categories from every configured language and labels each suggestion and selected category as "Name — Language" when the language is known, so same-named categories such as "Arancha — English" and "Arancha — Español" can be told apart, selected, removed and saved. Categories without a language keep their plain name.
