An add-on that a participant started paying for but did not finish (an abandoned, failed, cancelled or expired checkout) is offered again when they come back, and they can buy it on a later attempt. Only confirmed add-ons are treated as already bought, and with several tickets an add-on confirmed on one ticket can still be added to another. A participant whose own unfinished checkout holds an activity's last place can start a new attempt, and an activity filled by someone else is now reported as full instead of being silently dropped.
