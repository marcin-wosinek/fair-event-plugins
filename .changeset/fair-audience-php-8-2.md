Fair Audience now declares PHP 8.2 as its minimum in the plugin header and readme. Earlier releases declared PHP 8.0, but the spreadsheet libraries they bundled stopped the plugin from loading on any PHP older than 8.3. This release runs on PHP 8.2 and newer. Sites on PHP 8.0 or 8.1 must update PHP before installing it.
